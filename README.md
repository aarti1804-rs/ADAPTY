# ADAPTY
### Learn Your Way. Grow Every Day.

## About the Project

ADAPTY is an inclusive learning platform developed to make education easier and more accessible for students with disabilities.

Every student has a different way of understanding and learning. Some students may need better text readability, some may prefer audio support, while others may benefit from simple explanations and step-by-step practice.

ADAPTY brings these learning options together in one platform. It allows students to learn at their own pace and use the support that suits their needs.

## Why ADAPTY?

Many students face difficulties with traditional learning methods because the same teaching approach may not work equally well for everyone.

Through ADAPTY, we aim to make learning more flexible by providing accessible content, learning support and practice activities in one place.

## Key Features

- **Accessibility Settings:** Options such as high contrast, adjustable font size and line spacing for comfortable reading.
- **Subject Library:** Learning materials covering subjects like Mathematics, Science, English, Computer Fundamentals and Programming.
- **PDF Learning:** Students can upload their study material and extract text from PDF chapters.
- **Learning Support:** Provides relevant explanations and step-by-step help based on the selected lesson.
- **Practice Quiz:** Students can practise questions based on their lesson content.
- **Adaptive Learning:** Uses a Decision Tree model to suggest a learning level based on quiz performance and other learning factors.
- **Progress Tracking:** Saves learning activity and quiz results so students can review their progress.
- **Text-to-Speech:** Provides optional audio support for reading content.

## Technologies Used

- Python – Main programming language
- Streamlit – Web application interface
- Scikit-learn – Machine Learning
- TF-IDF – Text processing
- PyPDF – PDF text extraction
- SQLite – Storing student progress
- gTTS – Text-to-speech support

## How to Run the Project

**1. Clone the repository**

`git clone https://github.com/aarti1804-rs/ADAPTY.git`

**2. Open the project folder**

**3. Install the required libraries**

`pip install streamlit scikit-learn pypdf gTTS`

**4. Run the application**

`streamlit run app.py`

The application will open in your browser at the local address shown in the terminal.
